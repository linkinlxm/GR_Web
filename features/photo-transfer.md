# Transfer Ricoh GR photos to an iPhone with GR Link

GR Link connects the iPhone directly to a supported Ricoh GR camera's local Wi-Fi network. It does not send the camera's photos through a GR Link server.

## Supported files and workflow

1. Add or select the camera in GR Link.
2. Let GR Link establish the connection required by that model. GR II uses direct Wi-Fi; later models can use Bluetooth pairing and Wi-Fi handoff.
3. Open Gallery to browse photos stored on the camera.
4. Preview JPEG or DNG files and select the images to save.
5. Start the download. Live Activity can show progress from the Lock Screen on supported devices.

Downloaded images are saved to the iOS Photo Library or the app container according to the action the user chooses. Photos are not uploaded to a GR Link-operated service.

## Supported cameras

Photo browsing and transfer are supported across GR II, GR III, GR III HDF, GR IIIx, GR IIIx HDF, GR IV, GR IV HDF, and GR IV Monochrome. Connection details can differ by model and firmware. See the [full compatibility guide](https://gr-link.liljackson.org/compatible-cameras/).

Background transfers depend on iOS scheduling and the camera connection; a transfer may pause or need to be resumed.

## Troubleshooting

- Stay within a few metres of the camera during Wi-Fi transfer.
- Make sure another phone is not using the camera's Wi-Fi network.
- Keep Bluetooth enabled for models that use Bluetooth-to-Wi-Fi handoff.
- If iOS reports that the Wi-Fi network has no internet, remain connected: the camera network is intentionally local-only.
