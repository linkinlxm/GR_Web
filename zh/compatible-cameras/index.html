GR Link 支持的理光 GR 相机

支持 GR II 到 GR IV，包括 HDF 和 Monochrome 机型。应用会识别相机，并按机型调整连接、遥控、相册和配方功能。

兼容性概览

相机系列连接照片传输遥控与取景配方
GR II直接 Wi-FiJPEG/DNG取决于相机与固件配方库、导入导出
GR III / HDF蓝牙 + Wi-FiJPEG/DNG实时取景与遥控配方库与 iCloud 同步
GR IIIx / HDF蓝牙 + Wi-FiJPEG/DNG实时取景与遥控配方库与 iCloud 同步
GR IV / HDF蓝牙 + Wi-FiJPEG/DNG实时取景与遥控支持时写入 Custom 1/2/3
GR IV Monochrome蓝牙 + Wi-FiJPEG/DNG针对机型适配黑白配方

为什么功能会有差异？

不同代际的相机提供不同的蓝牙、Wi-Fi、遥控和影像控制接口。GR Link 会按机型隐藏不适用的操作；相机固件更新也可能改变实际表现。

遇到问题请将相机型号、固件、iOS 与 GR Link 版本发送至 support@liljackson.org。

GR Link 是独立开发的第三方应用，与 Ricoh Imaging Company, Ltd. 无从属、授权、合作、认可或赞助关系。
