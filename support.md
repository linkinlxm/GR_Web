# GR Link support

Contact [support@liljackson.org](mailto:support@liljackson.org?subject=GR%20Link%20Support). Replies are normally sent within two business days.

## Information to include in a bug report

1. Camera model and firmware version.
2. iPhone model and iOS version.
3. GR Link version from the Settings tab.
4. The exact steps that reproduce the problem.
5. Diagnostic logs, only when you choose to export and attach them.

## Supported cameras

GR Link supports GR II, GR III, GR III HDF, GR IIIx, GR IIIx HDF, GR IV, GR IV HDF, and GR IV Monochrome. Features vary by model. See the [compatibility guide](https://gr-link.liljackson.org/compatible-cameras/).

## Connection help

Bluetooth-equipped cameras must be in pairing mode before pairing inside GR Link. Live view and gallery access use the camera's local Wi-Fi connection. Stay close to the camera and disconnect other devices from its Wi-Fi if live view becomes unstable.

GR II connects directly by Wi-Fi rather than using the Bluetooth handoff flow of later models.

## Recipe sync

Recipe sync uses iCloud. Both devices must use the same Apple Account with iCloud Drive enabled. Changes can take several minutes to appear.
